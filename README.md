# posfija-y-prefija

El programa está organizado internamente en varias funciones que permiten realizar cada tarea de manera ordenada. La función mostrar_pila() se encarga de mostrar los elementos que se encuentran almacenados en la pila; evaluar_posfija() y evaluar_prefija() realizan las operaciones aritméticas de acuerdo con la notación elegida, y la función main() controla el menú principal, recibe las opciones del usuario y permite repetir el proceso hasta que se escriba FIN. Para trabajar, el programa utiliza una lista de Python como pila, en la que agrega números y retira los elementos necesarios para realizar las operaciones de suma, resta, multiplicación y división. Externamente, al ejecutar el programa, aparece un menú en la terminal con las opciones de notación posfija y prefija, además de la opción para terminar. El usuario selecciona la notación que desea utilizar e introduce una expresión aritmética con los números y operadores separados por espacios. Después, la terminal muestra los elementos que se van agregando o retirando de la pila, las operaciones que se realizan y los resultados obtenidos en cada paso, hasta mostrar el resultado final de la expresión. También se muestra el tiempo que tarda en evaluarse cada expresión y, cuando el usuario escribe FIN, aparecen los tiempos finales y el tiempo total de ejecución antes de que termine el programa.
